# SpatialStay Frontend — V10 Glass Travel Experience

This frontend redesign follows the supplied final visual direction while preserving SpatialStay's room-intelligence and spatial features.

## Included
- Responsive blue/white glassmorphism design system
- Three-transition cinematic home hero
- Search panel and AI/travel capability cards
- Hotel listing with functional client-side search, price, rating and amenity filters
- Hotel details with verified-property presentation and horizontal room rail
- Room details with Spatial Match, Room Reality and Review Intelligence
- Visual room comparison retained
- Interactive 3D/spatial room route retained and re-themed
- Booking summary route
- My Trips route
- One persistent Spatial AI launcher with chat and voice choices
- Mobile navigation and responsive layouts

## Run
```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Demo-data note
Hotel, room, review, price and booking information is frontend demo data. Live availability, payments, authentication, verified reviews and transaction confirmation must come from the future backend/source-of-truth services.
